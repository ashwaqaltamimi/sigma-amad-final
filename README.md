# Σ سيقما — منصة كشف شبكات غسيل الأموال للقطاع المصرفي

منصة ذكاء مالي تكشف **شبكات غسيل الأموال** التي تغيب عن الفحص التقليدي للعملية
الواحدة، وتحوّل الاشتباه إلى **بلاغ اشتباه (STR) نظامي جاهز** — عبر فريق وكلاء
رقمي يعمل تحت قرار بشري.

## المزايا الرئيسية

- **كشف متعدّد الطبقات** — رصد إحصائي + قواعد مكافحة الغسيل بعتبات تتكيّف مع
  تصنيف مخاطر العميل + تحليل شبكي.
- **التحليل الشبكي** — يرسم العلاقات بين الحسابات ويكشف الحلقات المغلقة وشبكات
  التجميع والتمرير التي لا تظهر في فحص العملية المفردة.
- **امتثال ساما** — يربط كل اشتباه بمادته النظامية (المادة 15) ويُجهّز مسودة
  بلاغ STR بحقول منظمة.
- **ذاكرة تتعلّم وتصمد عبر الجلسات** — كل قرار مراجعة بشري يُحفظ ويرفع دقة النظام
  في كل تشغيل قادم.
